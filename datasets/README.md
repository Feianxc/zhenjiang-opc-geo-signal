# 镇江OPC创业 GEO 自然问法评测数据包

用途：把“正常提示词里是否自然出现网易（镇江）联合创新中心”变成可复测的公开基准。

核心规则：

- 测试问题不提供客户名。
- 测试问题不提供 URL。
- 测试问题不粘贴资料。
- 答案自然提到“网易（镇江）联合创新中心”或“网易镇江联合创新中心”才算品牌命中。
- 如果把 OPC 误判为工业 OPC/OPC UA/离岸公司，则记录为语义误判。

文件：

- `entity-facts.json`：公开实体事实。
- `natural-opc-prompts.csv`：自然提示词。
- `answer-benchmark.jsonl`：评测规则。

隐私：不包含私人手机号。
